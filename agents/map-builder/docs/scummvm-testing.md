# ScummVM Testing Instructions

How to test Lost Vale maps in ScummVM's Ultima 8 engine.

## Prerequisites

1. **ScummVM** — latest version with Ultima 8 support
   - Download from https://www.scummvm.org/
   - Ultima 8 engine support is built-in since ScummVM absorbed Pentagram (2020)

2. **Ultima 8 game data** — from the GOG edition
   - The game data is in `shared/data/u8-install/`
   - Key files: `static/FIXED.DAT`, `static/GLOB.FLX`, `static/TYPEFLAG.DAT`,
     `static/U8SHAPES.FLX`

3. **Modified FIXED.DAT** — generated by the map tools
   - Test file: `shared/maps/FIXED_TEST.DAT`
   - This contains all 42 original maps + Map 10 (Lost Vale test)

## Quick Start

### 1. Set up the game directory

Create a working copy of the U8 game data:
```bash
cp -r shared/data/u8-install/ /tmp/u8-test/
```

### 2. Replace FIXED.DAT with the test version

```bash
cp shared/maps/FIXED_TEST.DAT /tmp/u8-test/static/FIXED.DAT
```

### 3. Add the game to ScummVM

Open ScummVM, click "Add Game", and point it to `/tmp/u8-test/`.
ScummVM should detect it as "Ultima VIII: Pagan".

### 4. Access Map 10

Once in the game, use ScummVM's built-in debugger to teleport to Map 10:

**ScummVM debugger commands:**
- Press **Ctrl+D** (or **Cmd+D** on Mac) to open the debugger console
- Type: `teleport 10 12800 2048 0` — teleports to Map 10 at the entry point
- Type: `exit` to close the debugger

### 5. Verify the test map

On Map 10 you should see:
- Terrain tiles (glob 1757 pattern) covering a 10x10 chunk area
- A stone marker near the entry point (shape 277)
- Rock decorations (shapes 65, 92)
- A small 3x3 water area (shape 347 — lake)
- Teleport eggs at various positions (invisible in-game)

## ScummVM Debugger Reference

| Command | Description |
|---------|-------------|
| `teleport <map> <x> <y> <z>` | Teleport Avatar to coordinates |
| `currentmap` | Show current map number |
| `item_search <shape>` | Find items with a given shape |
| `togglepaint` | Toggle map painting/debug view |
| `god` | Toggle god mode (invincibility) |
| `help` | List all available commands |

## Testing Transitions

To test teleport egg transitions:

1. Teleport to the TRIGGER egg position on Map 10
2. Walk the Avatar over it
3. The engine should transition to the destination map
4. Walk back over the corresponding TRIGGER on the destination map
5. Verify return to Map 10

**Test transition IDs in the test map:**

| ID | From | To | Test Position |
|----|------|----|---------------|
| 204/205 | Map 11 → Map 10 | Entry area | (12800, 2048, 0) |
| 206/207 | Map 10 → Map 13 | Cloud approach | (9216, 10240, 0) |
| 210/211 | Map 10 → Map 18 | Temple approach | (16384, 10240, 0) |
| 212/213 | Map 10 → Map 8 | Pagan return | (12288, 1536, 0) |

**Note:** Transitions will only work if destination maps (9, 11, 13, 17, 18)
also exist with corresponding DEST eggs. The test map only populates Map 10.

## Generating Custom Test Maps

Use `src/u8_map.py` to create custom maps:

```python
import sys
sys.path.insert(0, 'agents/map-builder/src')
from u8_map import MapArchive, MapItem, generate_terrain_grid

# Load existing data
archive = MapArchive('shared/data/u8-install/static/FIXED.DAT')

# Create items for a new map
items = []

# Add terrain
items.extend(generate_terrain_grid(
    x_start=8192, y_start=1024,
    x_chunks=5, y_chunks=5,
    glob_index=1757
))

# Add a teleport
items.append(MapItem.teleport_dest(
    x=10240, y=3072, z=0,
    teleport_id=200, dest_npc=200, dest_map=8
))

# Set map and save
archive.set_map_items(10, items)
archive.save('shared/maps/FIXED_CUSTOM.DAT')
```

## Known Limitations

1. **No new shapes** — the test map uses only shapes that exist in U8SHAPES.FLX.
   New art (god figures, Harpie, etc.) would need shape archive modifications.

2. **No usecode** — the test map has no usecode hooks. Egg triggers for PLNTST,
   MAGNET, FREE, etc. require compiled usecode in USECODE.FLX.

3. **NPC placement** — NPCs need entries in the NPC table (separate from map
   items) and compiled usecode for conversations.

4. **Glob visual verification** — the selected glob (1757) produces terrain
   appropriate for the Plateau. Different globs should be tested for Lost Vale
   aesthetics.
